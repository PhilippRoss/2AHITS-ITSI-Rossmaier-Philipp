# Aufgabe 1:
Recherchiere, experimentiere und erkläre die folgenden Optionen:

-m
-l
-L
-w
Finde heraus (Recherchieren, Experimentieren) was die folgende Kommandozeile macht (lies die man page von wc ab “Description”):

$ echo eins zwei drei | wc - klassenkassa.csv
## Lösung: 
- -m: gibt nur die Zeichen anzahl aus(inklusive zeilen umbruch)
- -l: gibt nur die Zeilen anzahl aus(zählt zeilen umbrüche)
- -L: gib die Zeichen anzahl der längsten zeile aus
- -w: gibt die Wörter anzahl aus

Er zählt denn inhalt des echo und dann den von der Klassenkassa addiert alles und gibt dass dan aus (die individuellen inhäter auch)

# Aufgabe 2.3:
Schreibe ein shell Kommando (Einzeiler) das in klassenkassa.csv alle Beträge mit dem Text Werkstatt in folgender Form ausgibt:

3.0+15.0+3.0+13.0+2.5

Anleitung:

Verwende grep um die Zeilen mit Werkstatt zu filtern.
Verwende nicht die -c Option von grep.
wende cut auf das Ergebnis an um nur die Geld-Beträge zu filtern
Die Beträge stehen nun auf einzelnen Zeilen. Verwende das Tool paste um diese zu einer Zeile zusammenzufassen.
## Lösung:
``` shell 
grep "Werkstatt" klassenkassa.csv | cut -d',' -f3 | paste -sd+ 
```
